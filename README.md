# IncomePulse — AI Stock & Options Income Studio

An intuitive, bilingual (**Arabic / English**) Python web dashboard for stock market forecasting and repetitive income option strategies—powered by **100% free public data sources**.

## Deploy Free to Your iPhone (Streamlit Community Cloud)

1. Push this folder to a free GitHub repository (public or private).
2. Go to [share.streamlit.io](https://share.streamlit.io), sign in with GitHub, and click **New app**.
3. Select your repository, set **Main file path** to `app.py`, and click **Deploy**.
4. Open your live `https://...streamlit.app` link in **Safari** on your iPhone → tap **Share (`↑`)** → **Add to Home Screen**.

## Run Locally on Mac

```bash
./run.sh
```

Then open [http://localhost:8501](http://localhost:8501).
